# 範例任務：機台異常偵測

一份可以直接放上平台的完整任務：評分程式、隱藏測試資料、給學生的訓練資料與範本，以及 7 份分數不同的範例提交。只用 Python 標準函式庫，預設執行環境 `python:3.12-slim` 不用另外裝套件。

## 檔案

| 檔案 | 用途 | 誰看得到 |
|---|---|---|
| `grade.py` | 評測程式（上傳到「評測程式」） | 只有老師 |
| `hidden/test.csv` | 500 筆含答案的測試資料（上傳到「隱藏資料」） | 只有老師 |
| `train.csv` | 800 筆含答案的訓練資料，附在任務說明給學生下載 | 學生 |
| `starter.py` | 學生範本，可在本機用 train.csv 自我檢查 | 學生 |
| `make_data.py` | 重新產生資料：`python make_data.py --seed 7` | 只有老師 |
| `train_logistic.py` | 參考解法的訓練流程（離線訓練邏輯迴歸、印出權重） | 只有老師 |
| `submissions/` | 範例提交，用來試跑與示範排行榜 | 只有老師 |

> `train.csv` 與 `hidden/test.csv` 不在 repo 裡（`.gitignore` 已排除），先執行 `python make_data.py` 產生。這個 repo 是公開的，預設種子產生的資料任何人都能重現；正式出給學生時請用 `python make_data.py --seed <只有你知道的數字>`。

## 任務說明（可直接貼上）

```markdown
實驗室的機台每小時回報一次感測數據。請預測**接下來一天內會不會故障**，讓我們提早安排保養。

### 資料
附件 `train.csv` 有 800 筆歷史紀錄：

| 欄位 | 說明 |
|---|---|
| temperature | 機台溫度（°C） |
| vibration | 震動強度（mm/s RMS） |
| current | 電流（A） |
| hours_since_service | 距離上次保養的小時數 |
| label | 1 = 一天內故障，0 = 正常（約 25% 為 1） |

### 要交什麼
一個 Python 檔，定義 `predict(rows)`：輸入一串 dict（欄位同上、沒有 label），回傳同樣長度的 0／1 清單。可以先下載 `starter.py` 修改。

### 評分
用 500 筆隱藏資料計算故障類別的 **F1 分數**，F1 ≥ 0.60 算通過，排行榜以 F1 排名。只能用 Python 標準函式庫，評測時沒有網路，也讀不到 train.csv，訓練好的參數請直接寫在程式裡。
```

## 範例提交與分數

用 `python grade.py <提交目錄> hidden <輸出目錄>` 實際跑過（與平台的呼叫方式相同）：

| 提交 | 結果 | F1 | 說明 |
|---|---|---|---|
| `01_all_normal.py` | 未通過 | 0.000 | 全部判為正常；準確率有 75%，但一台故障都沒抓到 |
| `02_temperature_only.py` | 未通過 | 0.378 | 只看溫度 |
| `03_two_rules.py` | 未通過 | 0.508 | 溫度或震動兩條規則 |
| `04_risk_score.py` | 通過 | 0.788 | 手調的加權風險分數 |
| `05_logistic.py` | 通過 | 0.808 | 邏輯迴歸＋交互作用項（參考解） |
| `06_wrong_length.py` | 未通過 | — | 回傳筆數不對：「回傳 93 筆，但輸入有 500 筆」 |
| `07_crash.py` | 未通過 | — | 欄位打錯：「KeyError: 'temp'（main.py 第 3 行）」 |

通過的提交還會列出各情境的準確率（高溫、強震動、久未保養、一般運轉），讓學生知道模型在哪裡弱。
