# 範例任務：活動資料來源收集（BAB-6）格式驗證

學生交 20 欄的活動資料表（CSV 或 XLSX），平台依 `sample_events.xlsx`「欄位規格」逐列檢查。每個錯誤都標出**第幾列、哪一欄**；老師和學生按「檢視資料」就能在平台上看到檔案內容，並查看錯誤標在哪一格。只用 Python 標準函式庫。

## 檔案

| 檔案 | 用途 |
|---|---|
| `grade.py` | 評測程式（上傳到「評測程式」）；也可以在本機當驗證腳本用 |
| `make_bad_samples.py` | 用 `sample_events.csv` 產生 4 份帶錯的範例到 `bad/` |

`sample_events.csv`／`.xlsx` 是作業附件，請自己放進這個資料夾（`.gitignore` 已排除，不會進公開 repo）。

## 平台設定

| 欄位 | 值 |
|---|---|
| 提交方式 | 檔案 |
| 允許的副檔名 | `.csv,.xlsx` |
| 評測程式 | `grade.py` |
| 隱藏資料（選填） | `config.json`：`{"from": "2016-10-07", "to": "2026-10-07"}`，要涵蓋的期間；哪一年沒有任何活動會列為警告 |
| 執行環境 | `python:3.12-slim`（預設），需求套件留空 |
| 分數方向 | 越高越好（分數＝沒有錯誤的列數比例，0–100） |
| 排行榜 | 關閉 |

ERROR 0 才算通過；WARNING 不影響通過。試跑時上傳 `sample_events.csv` 應該通過。

## 檢查項目

- **檔案**：UTF-8 CSV（可含 BOM）或 XLSX（讀第一個工作表）；Big5 等其他編碼直接回報「不是 UTF-8」。
- **表頭**：20 欄都要有、前 5 欄順序固定；可以多欄。
- **逐列**：
  - 必填欄位；縣市名稱（要用「臺」）；高雄市 38 區，跨區用「、」。
  - 日期格式 `YYYY-MM-DD`；`活動時間` 的 ` ~ ` 前後要有空白；單日活動不能寫成區間；開始／結束日期要跟活動時間一致。
  - 活動編號 `KHH-YC-年-流水號`、全檔唯一（年份和開始日期不同時給警告）。
  - 活動類型、範圍判定、來源類型、可信度只能填規定的值。
  - 來源名稱／類型／網址的筆數要一樣；網址要是完整的 http(s)；佐證來源數要等於網址數。
  - 可信度「中／低」時備註必填；「高」卻只有一個非官方來源時給警告。
  - 擷取日期不可晚於今天。
- **年份覆蓋**：設定期間內，沒有任何活動的年份列為警告。

## 本機使用（學生交件前自己跑）

```bash
python grade.py --file 我的檔案.csv --from 2016-10-07 --to 2026-10-07
```

```
ERROR 8｜WARNING 2｜10 筆資料，2 筆沒有錯誤。ERROR 要是 0 才算通過
  [ERROR] 第 2 列 活動時間：格式要是 YYYY-MM-DD 或 YYYY-MM-DD ~ YYYY-MM-DD（~ 前後各一個空白），目前是「2022/2/26 ~ 2022/2/27」
  [ERROR] 第 3 列 縣市：「台北市」不是正式名稱，請用「臺」不用「台」
  ...
```

列號從表頭下一列算起，跳過空白列，跟平台資料檢視器的列號一致。

## 範例結果

| 檔案 | 結果 |
|---|---|
| `sample_events.csv`／`.xlsx` | 通過；ERROR 0、WARNING 6（2016–2021 年沒有資料） |
| `bad/01_common_mistakes.csv` | ERROR 8：日期格式、台北市、區域分隔、缺網址、編號重複、來源數不符、低可信度沒寫備註、類型不在清單 |
| `bad/02_missing_column.csv` | ERROR 1：缺少「來源類型」欄位，不逐列檢查，分數 0 |

| `bad/04_almost_right.csv` | ERROR 1：單日活動寫成「X ~ X」 |
