# [MS-16] 上傳圖片並顯示在內文中

> 狀態：待辦

## 內文

### 需求
學生要能把截圖、照片放進會議紀錄，和 Markdown 內文一起顯示。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/02-architecture.md` §5；待確認 #5

### 驗收條件
- [ ] 支援三種方式：工具列按鈕、貼上、拖放；可一次多張
- [ ] 上傳中在游標處顯示佔位與進度，完成後換成圖片；失敗顯示原因與重試，不留下壞掉的圖片語法
- [ ] 上傳前在瀏覽器壓縮（長邊 2560px）；GIF 保留動畫
- [ ] 預覽中圖片與文字一起顯示，點擊放大檢視，可左右切換同份文件的圖片
- [ ] 圖片只有能讀這份紀錄的人看得到（直接貼網址給未授權的人會看到找不到）
- [ ] 超過每人配額時顯示「儲存空間已滿（已用 X / Y）」

### 測試流程
1. 在會議紀錄貼上一張剪貼簿截圖，看到上傳進度後顯示在預覽中
2. 拖放三張照片，全部顯示，點擊可放大並左右切換
3. 上傳中斷網路，看到失敗與重試按鈕，重試成功
4. 用未登入的瀏覽器開圖片網址，得到找不到
