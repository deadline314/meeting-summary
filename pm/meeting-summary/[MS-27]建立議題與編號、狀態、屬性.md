# [MS-27] 建立議題與編號、狀態、屬性

> 狀態：待辦

## 內文

### 需求
專案底下的議題要有 Linear 風格的編號、狀態、優先級、負責人、標籤，且所有變更都有完整的活動紀錄。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/05-project-management.md` §3、§8

### 驗收條件
- [ ] 議題編號 `KEY-N`，同時大量建立也不重號、不跳號重用
- [ ] 6 種狀態（Backlog、Todo、進行中、審查中、完成、已取消）與 5 級優先級，圖示與顏色依 §8
- [ ] 負責人可多位，第一位為主要負責人；只能指派看得到該專案的人
- [ ] 標籤屬於單一專案，顏色從 8 色 token 選；擁有者可管理標籤
- [ ] 截止日；描述為 Markdown
- [ ] 每次變更寫結構化活動（欄位、從、到、誰、何時、來源 web／mcp／system），存 id 不存名稱，只增不刪
- [ ] 議題、留言軟刪除，可由擁有者還原
- [ ] 已結案、已封存專案在伺服器端拒絕新增議題

### 測試流程
1. 在 CATS 連續快速建立 20 張議題（含並行），編號 CATS-1 到 CATS-20 不重複
2. 改狀態、優先級、負責人、標籤，活動依序記錄從→到
3. 負責人改名後，活動紀錄顯示新名稱
4. 嘗試指派非成員，被拒絕並說明原因
5. 把專案結案後透過 API 開票，被拒絕
