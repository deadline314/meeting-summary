# [MS-14] 查看會議紀錄的編輯歷史

> 狀態：待辦

## 內文

### 需求
要能看到誰在什麼時候改了什麼，必要時把內容還原到之前的版本。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/03-meeting-notes.md` §5

### 驗收條件
- [ ] 歷史面板列出每個編輯段落：誰、何時、+N／−M 字（同一人閒置 5 分鐘內的編輯合併為一段）
- [ ] 點選任一段落顯示該版本與前一版的差異（新增綠色、刪除紅色），手機上可閱讀
- [ ] 可以還原到任一版本，還原前用確認框說明「會以目前內容建立新版本，不刪除歷史」；還原本身也記為一筆編輯
- [ ] 歷史只增不刪，任何人都無法刪除歷史段落
- [ ] 歷史以分頁載入，100 個段落以上仍順暢

### 測試流程
1. A 寫一段，等 5 分鐘；B 刪掉一句
2. 打開歷史，看到兩個段落，各自顯示正確的人與字數
3. 點 B 的段落，看到被刪的那句以紅色顯示
4. 還原到 A 的版本，內容恢復，歷史多一筆「還原」
