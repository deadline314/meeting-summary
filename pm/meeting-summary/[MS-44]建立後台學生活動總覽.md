# [MS-44] 建立後台學生活動總覽

> 狀態：待辦

## 內文

### 需求
老師要能看到學生什麼時候編輯了什麼：會議紀錄的編輯、提交、議題變更，一個地方看完。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/03-meeting-notes.md` §5、`design/04-tasks.md` §2

### 驗收條件
- [ ] 全站活動流：時間、誰、做了什麼（編輯會議紀錄 +N／−M 字、提交任務與結果、議題變更、留言、註解），點擊前往並定位到該處
- [ ] 可依成員、模組、日期範圍篩選，篩選寫在網址
- [ ] 成員個人頁：該成員的會議紀錄參與、任務提交與成績、議題，以及近 12 週活動熱度圖
- [ ] 可匯出 CSV
- [ ] 活動以分頁載入，1 萬筆以上仍順暢
- [ ] 管理員看不到私人專案與對管理員隱藏的專案中的活動

### 測試流程
1. 學生 A 編輯會議紀錄、提交任務、改一張議題
2. 老師在活動流篩選 A，看到三筆並可點進去，會議紀錄打開時對應版本差異
3. 打開 A 的個人頁看到熱度圖與成績
4. 匯出 CSV 內容與畫面一致
