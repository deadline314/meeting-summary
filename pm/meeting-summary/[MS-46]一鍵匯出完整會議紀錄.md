# [MS-46] 一鍵匯出完整會議紀錄

> 狀態：待辦

## 內文

### 需求
會議紀錄要能一鍵完整匯出帶走或交給別人：內容包含會議資訊表頭與全部內文，上傳的圖片要出現在內文原本的位置，附件也一起帶出，離開平台也能完整閱讀。

### 來源
使用者 2026-10-19 對話：「還要可以一鍵完整匯出會議紀錄（包含上傳的圖片等等要插入在正確位置）」

### 驗收條件
- [ ] 會議紀錄頁的選單有「匯出」，可選兩種格式：ZIP（Markdown＋圖片與附件資料夾）、單一 HTML 檔（圖片內嵌）
- [ ] ZIP 解壓後用任何 Markdown 編輯器打開，圖片顯示在與平台上相同的位置（連結改成 ZIP 內的相對路徑）
- [ ] ZIP 內附上這份紀錄的所有附件；Google Drive 連結列在附件清單中（不下載 Drive 檔案）
- [ ] HTML 檔離線用瀏覽器打開，表頭、表格、待辦、程式碼、圖片都正確顯示，深淺色皆可閱讀，可直接列印成 PDF
- [ ] 匯出內容是按下當下的最新版本（包含尚未同步到列表的即時編輯）
- [ ] 匯出時顯示進度；某張圖片讀取失敗時仍完成匯出，並在該位置保留原連結與提示
- [ ] 檔名為「日期_會議名稱」，中文檔名不亂碼
- [ ] 只有能讀這份紀錄的人能匯出；匯出不消耗伺服器運算額度（在瀏覽器端組裝）

### 測試流程
1. 在一份有 2 張圖片與 1 個 PDF 附件的會議紀錄，按「匯出 → ZIP」
2. 解壓後用 VS Code 預覽 Markdown，圖片位置與平台相同，附件資料夾有 PDF
3. 按「匯出 → HTML」，關閉網路後打開檔案，內容與圖片完整，按列印預覽為正常版面
4. 另一人正在編輯時匯出，匯出內容包含對方剛打的字
