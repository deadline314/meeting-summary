# [MS-7] 讓使用者隨時修改顯示名稱

> 狀態：待辦

## 內文

### 需求
使用者可以隨時改名稱，改完之後全站所有地方（包含舊的會議紀錄、留言、活動紀錄、作者標示）都要立刻顯示新名稱。

### 來源
使用者 2026-10-19 對話（初始需求）

### 驗收條件
- [ ] 設定頁可修改名稱與頭像（上傳或用 Google 頭像），名稱 1–40 字，前後空白自動去除
- [ ] 改名後不重新整理，目前畫面上所有出現此人的地方立刻更新
- [ ] 其他人的畫面在下一次載入或 1 分鐘內更新為新名稱
- [ ] 過去的活動紀錄、留言、註解、@提及、作者標示、排行榜都顯示新名稱
- [ ] 活動紀錄記一筆「改名：舊 → 新」，管理員後台查得到

### 測試流程
1. A 在會議紀錄寫一段、在議題留言、被 @ 一次
2. A 改名
3. A 自己畫面上的頭像選單、留言、作者標示立刻變新名稱
4. B 重新整理後在同樣位置看到新名稱，@提及 pill 也是新名稱
