# [MS-35] 支援留言、提及與活動時間軸

> 狀態：待辦

## 內文

### 需求
團隊要能在票上討論，提到人或其他票時對方收得到、能點過去。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/05-project-management.md` §5.5

### 驗收條件
- [ ] 留言支援 Markdown、@ 叫出成員（只列看得到此專案的人）、# 搜尋議題，顯示成 pill；被 # 引用的票反向記一筆「被引用」
- [ ] 回覆只有一層；只能編輯、刪除自己的留言，編輯過顯示「已編輯」
- [ ] 時間軸合併留言與變更，可篩選全部／留言／變更、切換排序、「載入更早」分頁
- [ ] 輸入框自動長高到 40% 視窗高度為止，不能手動拖曳；插入 mention 或自動接續清單時捲動位置不跳
- [ ] 留言可貼上圖片

### 測試流程
1. 在留言 @B 並 # 引用 CATS-5，送出後顯示 pill
2. CATS-5 時間軸出現「被引用」
3. 編輯自己的留言，顯示已編輯；無法編輯別人的留言
4. 連續輸入 30 行，輸入框長到 40% 後改為內部捲動
