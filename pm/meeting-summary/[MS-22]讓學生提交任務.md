# [MS-22] 讓學生提交任務

> 狀態：待辦

## 內文

### 需求
學生要能上傳檔案或貼上程式碼來提交任務，並即時看到評測進度與結果。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/04-tasks.md` §3

### 驗收條件
- [ ] 任務頁可上傳檔案（依任務允許的格式）或貼上程式碼提交
- [ ] 提交後狀態即時更新：排隊中 → 執行中 → 通過／未通過／錯誤／逾時，不需重新整理
- [ ] 未通過時清楚顯示原因（評測程式的訊息、各測試項目結果）與截斷後的執行紀錄
- [ ] 超過截止時間、超過每日上限、格式不符時無法提交，並說明原因與下次可提交時間
- [ ] 學生只看得到自己的提交
- [ ] 任務列表顯示每個任務的狀態：未提交／已通過／未通過、最佳分數、截止倒數

### 測試流程
1. 學生上傳一份正確的提交，看到狀態依序變化，最後顯示通過與分數
2. 上傳一份錯誤的提交，看到未通過與具體原因
3. 當日提交達上限後再提交，被拒絕並顯示可再提交的時間
4. 另一位學生看不到第一位學生的提交
