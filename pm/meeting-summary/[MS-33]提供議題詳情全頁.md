# [MS-33] 提供議題詳情全頁

> 狀態：待辦

## 內文

### 需求
打開一張票要看到完整內容與屬性，並能不回清單就連續看下一張。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/05-project-management.md` §2（PROJ-44）、§5.4

### 驗收條件
- [ ] 左欄由上到下：衝突橫幅、父票 chip 與「被 N 張票擋住」、標題（就地編輯）、描述（Markdown，`- [ ]` 可直接勾選）、子議題、關聯、附件、時間軸
- [ ] 右欄：狀態、優先級、負責人、標籤、截止日、建立資訊、停滯徽章；手機上右欄移到標題下方並可收合
- [ ] 有上一張／下一張（[ ／ ]），順序沿用進來時的清單與篩選排序；直接用網址開啟時不顯示
- [ ] 返回清單時回到原捲動位置並選中剛看的票
- [ ] 別人更新這張票時出現衝突橫幅與重新載入按鈕
- [ ] 勾選描述中的待辦時，若原文與畫面不一致則拒絕並提示重新載入

### 測試流程
1. 從篩選後的清單打開第 3 張，按 ] 到第 4 張，順序與清單一致
2. 按返回，清單捲動位置不變且第 4 張被選中
3. 在描述中勾一個待辦，重新整理後仍勾選
4. B 修改同一張票，A 的畫面出現衝突橫幅
