# [MS-21] 讓老師建立任務與評測設定

> 狀態：待辦

## 內文

### 需求
老師、學長要能出任務：寫說明、設期限、上傳評測程式與資料，並先試跑確認評測正確再發布給學生。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/04-tasks.md` §1、§2、§4；待確認 #7

### 驗收條件
- [ ] 管理員可建立任務：標題、說明（Markdown 可放圖）、開始與截止時間、可見對象（全站或指定專案）、提交格式、檔案上限、每日提交上限、是否開放排行榜、分數方向
- [ ] 評測設定：上傳評測程式與隱藏資料、選執行環境與需求套件、時間與記憶體上限；評測程式合約說明在頁面上可展開查看
- [ ] 必須用範例提交試跑成功才能發布；試跑結果顯示分數、訊息與執行紀錄
- [ ] 發布後可修改說明與截止時間；改評測程式時可選擇「重新評測全部提交」並顯示預估耗用分鐘數
- [ ] 建立／發布／修改都記活動
- [ ] 設定頁切成 Tab：說明、評測、提交規則、預覽，單頁不擁擠
- [ ] 學生看不到評測程式與隱藏資料

### 測試流程
1. 管理員建立任務、上傳評測程式，用範例提交試跑，看到分數
2. 試跑失敗時「發布」按鈕不可按，hover 顯示原因
3. 發布後學生帳號看到任務與說明，但看不到評測程式
4. 修改評測程式並選擇重新評測全部，所有提交重新跑過
