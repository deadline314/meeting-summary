# [MS-50] 正確顯示與處理議題阻擋關係

> 狀態：進行中

## 內文

### 需求
議題可以設定 Blocks／Blocked by，但目前只看得到「被幾張阻擋」，看不出這張阻擋了誰；跨專案的阻擋者顯示成「?-3」，還會露出自己看不到的專案的議題標題；可以設定互相阻擋的循環；阻擋者完成後被阻擋的人不會知道；也無法篩出被阻擋的議題。阻擋關係的顯示、篩選、通知與防呆都要正確。

### 來源
使用者 2026-10-20 對話：「專案有沒有被 Block、被誰 Block 整體的 UIUX 跟操作邏輯都要正確」

### 驗收條件
- [ ] 清單、看板卡片顯示「被阻擋」（列出未完成的阻擋者）與「阻擋 N 張」兩種標示，hover 列出編號與標題，點擊可前往
- [ ] 詳情頁上方顯示「被 X、Y 阻擋」與「阻擋 Z」，已完成或取消的阻擋者以刪除線列在關聯區，不計入「被阻擋」
- [ ] 跨專案阻擋者顯示正確編號；看不到的專案的議題只顯示「1 張無權檢視的議題」，不露出標題與編號
- [ ] 不能設定互相阻擋或形成阻擋循環（A→B→C→A），畫面與 API 都擋並說明原因
- [ ] 把仍被阻擋的議題改成進行中／審查中／完成時，跳出確認並列出阻擋者；可選擇仍要變更
- [ ] 最後一個阻擋者完成或取消時，被阻擋議題的負責人與訂閱者收到「已解除阻擋」通知（通知偏好可關閉）
- [ ] 篩選器可篩「被阻擋」與「阻擋他人」，網址保留篩選
- [ ] 移除阻擋關係記入活動紀錄，兩張議題的歷史都看得到

### 測試流程
1. 建立 A、B、C，設定 A blocks B、B blocks C；再設定 C blocks A，顯示「會形成循環」
2. 清單中 B 顯示「被 A 阻擋」與「阻擋 1 張」；篩「被阻擋」只出現 B、C
3. 把 B 拖到「進行中」，跳出確認列出 A
4. 把 A 改完成，B 的負責人收到「已解除阻擋」通知，B 不再顯示被阻擋
