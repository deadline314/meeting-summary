# [MS-25] 支援用 GPU 訓練模型

> 狀態：待辦

## 內文

### 需求
未來學生要在平台上提交訓練工作，用實驗室 GPU 機器訓練模型並看到過程與結果。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/04-tasks.md` §6

### 驗收條件
- [ ] 任務可設定為「訓練」類型，工作送到實驗室 GPU 機器（self-hosted runner）執行
- [ ] 訓練過程中即時顯示指標曲線（如 loss、accuracy）
- [ ] 訓練完成後產出物（模型檔、圖表）可下載或在頁面檢視
- [ ] 可取消執行中的訓練；同時執行數量有上限並顯示排隊順位
- [ ] GPU 機器離線時顯示「訓練機器離線」，工作保持排隊

### 測試流程
1. 提交一個訓練工作，看到排隊順位，開始後即時更新曲線
2. 訓練結束後下載模型檔
3. 關閉 GPU 機器，新提交顯示機器離線並保持排隊
