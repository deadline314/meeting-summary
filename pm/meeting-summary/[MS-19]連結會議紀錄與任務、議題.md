# [MS-19] 連結會議紀錄與任務、議題

> 狀態：待辦

## 內文

### 需求
每週會議要能連到待辦（議題）與任務，讓討論、待辦與學生提交的成果互相追得到。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/03-meeting-notes.md` §3、`design/04-tasks.md` §5

### 驗收條件
- [ ] 內文輸入 # 可搜尋並引用議題 `#[issue:KEY-N]` 與任務 `#[task:id]`，顯示成可點的 pill（含目前狀態）
- [ ] 被引用的議題與任務頁面顯示「被哪些會議紀錄提及」
- [ ] 「五、待辦事項」每列有「轉成議題」：選專案後建立議題，負責人與期限帶過去，該列自動補上議題引用；已轉過的列顯示議題狀態
- [ ] 看不到的議題或任務引用，對沒權限的人顯示為「無法存取的項目」，不洩漏標題
- [ ] 會議紀錄頁側邊列出本份引用到的所有議題與任務及其狀態

### 測試流程
1. 在討論事項輸入 # 搜尋並引用一張議題與一個任務
2. 打開該議題，看到「被會議紀錄提及」並可點回
3. 在待辦事項第一列按轉成議題，議題建立且負責人、期限正確
4. 用不是該專案成員的帳號開啟紀錄，引用顯示為無法存取
