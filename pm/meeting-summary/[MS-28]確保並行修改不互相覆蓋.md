# [MS-28] 確保並行修改不互相覆蓋

> 狀態：進行中

## 內文

### 需求
多人同時改同一張票或同一個專案時，不能讓後寫的人默默覆蓋先寫的人；介面要即時反應，失敗時自動還原並說明。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/05-project-management.md` §11、§13

### 驗收條件
- [x] 議題、專案、留言、標籤的所有修改都帶版本，版本不符時拒絕並回衝突
- [x] 拖曳、改欄位等操作先更新畫面再送出；遇到衝突自動回滾並顯示「已被其他人更新，已重新整理」，然後載入最新資料
- [x] 批次操作（1–50 張）部分失敗時顯示「N／M 筆失敗，已還原」，成功的保留
- [x] 外部寫入可帶 operation_id，重送不會重複執行
- [ ] 網路錯誤時自動重試（指數退避，最多 3 次），仍失敗則還原並提示

### 測試流程
1. A、B 同時打開 CATS-1；A 改狀態，B 接著改優先級
2. B 看到衝突提示，畫面更新為 A 的狀態，B 可再改一次
3. 批次改 10 張票，其中 2 張事先被別人改過，看到 2／10 失敗已還原
4. 用同一個 operation_id 呼叫兩次建立議題，只建立一張
