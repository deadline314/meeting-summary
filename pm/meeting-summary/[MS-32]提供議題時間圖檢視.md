# [MS-32] 提供議題時間圖檢視

> 狀態：待辦

## 內文

### 需求
時間圖讓人看到每張票在各狀態待了多久、有沒有逾期。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/05-project-management.md` §9

### 驗收條件
- [ ] 每張票畫成各狀態的時間段，資料從狀態變更活動推導，不另存
- [ ] Ctrl／⌘＋滾輪以游標為中心縮放，級距季、月、週、日；= 放大、- 縮小、T 跳到今天
- [ ] 今天線、專案目標日期（逾期變紅）、議題截止日刻線
- [ ] hover 時間段顯示狀態與停留時間
- [ ] 單一專案最多 500 張，超過時提示用篩選縮小範圍
- [ ] 有全站時間圖總覽（G O），只含自己可見的專案
- [ ] 單張票資料異常時補預設值，不影響整張圖
- [ ] 手機上可雙指縮放與左右拖動

### 測試流程
1. 打開有 50 張票的專案時間圖，用滾輪縮放到週級距
2. 按 T 回到今天
3. hover 一段進行中，顯示停留天數
4. 設定一個已過的目標日期，標記變紅
