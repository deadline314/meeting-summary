# [MS-42] 讓使用者產生 API Key 接 MCP

> 狀態：待辦

## 內文

### 需求
大家要能用 Claude Code、Claude Desktop 等外部 AI 透過 MCP 新增、修改票與專案，設定越簡單越好：自己產生金鑰，一行就加好。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/02-architecture.md` §7、`design/05-project-management.md` §12

### 驗收條件
- [ ] 設定頁可產生 API Key：命名、scope（read／write／manage）、可限定專案、到期日；建立時只顯示一次，可撤銷；列出最後使用時間
- [ ] 產生後直接顯示可複製的一行加入指令（Claude Code）與網址形式（只能填網址的客戶端），網址形式旁標示「網址含金鑰，勿分享」
- [ ] MCP 工具涵蓋：專案（列出、詳情、建立、成員、結案）、議題（查詢、建立、修改、批次修改、留言、附件）、會議紀錄（查詢、讀取、建立）、任務（列出、查看自己的提交結果）
- [ ] 權限與網頁完全一致：看不到的專案回找不到；scope 不足時回明確錯誤
- [ ] REST 用 API Key 呼叫時同樣受 scope 限制
- [ ] 每次呼叫重新檢查金鑰與帳號狀態，撤銷或帳號停用後立即失效
- [ ] MCP 的寫入在活動紀錄標示來源 mcp；支援 operation_id 冪等
- [ ] 每把金鑰有呼叫頻率上限，超過時回明確錯誤

### 測試流程
1. 產生一把 write 金鑰，複製一行指令貼到 Claude Code，成功加入
2. 在 Claude Code 請它在 CATS 開一張票並留言，網頁上看到該票且活動來源為 mcp
3. 用限定專案的金鑰查詢另一個專案，得到找不到
4. 撤銷金鑰後再呼叫，立即失敗
