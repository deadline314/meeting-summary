# [MS-11] 建立會議紀錄與預設範本

> 狀態：待辦

## 內文

### 需求
學生要能建立會議紀錄，設定會議名稱、時間、地點、記錄人、出席、缺席等欄位，內文自動帶入建議格式，而且前次待辦會自動帶過來。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/03-meeting-notes.md` §1–§3、§7；待確認 #6

### 驗收條件
- [ ] 新增會議紀錄時填寫：名稱、日期時間（起訖）、地點（文字或連結，連結可點）、記錄人（預設自己）、出席、缺席與原因、所屬專案（選填）
- [ ] 內文自動帶入預設範本（依介面語系），表頭表格由欄位產生，改欄位內文表頭同步更新
- [ ] 同系列（同名稱或同專案）上一份紀錄的「五、待辦事項」自動帶入「二、前次待辦追蹤」，狀態預設「進行中」
- [ ] 管理員可在後台修改站台預設範本，修改後新建立的紀錄使用新範本
- [ ] 出席、記錄人用 @ 選成員，顯示目前名稱
- [ ] 權限：預設全站成員可讀；建立者、記錄人、出席者可編輯；管理員與老師可編輯全部；掛在專案下可設為僅限專案成員
- [ ] 刪除為軟刪除，只有建立者、管理員、老師可刪，刪除前用確認框說明後果

### 測試流程
1. 建立「每週進度會議」，填入所有欄位，內文出現範本且表頭與欄位一致
2. 修改地點為 Google Meet 連結，表頭同步更新且連結可點
3. 在第一份的待辦事項填兩列，再建立下一週同名會議，前次待辦追蹤出現那兩列
4. 用非出席者的學生帳號開啟，只能讀不能編輯
