# [MS-51] 補齊各處的右鍵選單

> 狀態：進行中

## 內文

### 需求
只有議題清單與看板卡片有右鍵選單，其他常用物件（側欄專案、會議紀錄、任務、留言、附件、看板欄）按右鍵只出現瀏覽器預設選單。參考 Linear、Notion、GitHub 的慣例，在這些地方提供合適的右鍵選單，選單內容只出現使用者有權限做的動作，手機長按同樣可用。

### 來源
使用者 2026-10-20 對話：「我發現好像沒有設計點擊右鍵的功能。幫我補上合適的功能們，如果不確定就參考其他專案的」

### 驗收條件
- [ ] 側欄專案：開啟、在新分頁開啟、新增議題、新增子專案、專案設定、管理成員、複製連結、結案／封存（依權限）
- [ ] 看板欄標題：在此欄新增議題、收合／展開
- [ ] 會議紀錄列表：開啟、在新分頁開啟、複製連結、匯出 ZIP／HTML、刪除（依權限）
- [ ] 任務列表：開啟、在新分頁開啟、複製連結、編輯任務（管理者）
- [ ] 留言（議題與會議紀錄）：回覆、複製內容、複製連結、編輯、刪除（只對自己的留言或有權限者）
- [ ] 附件：開啟、下載、複製連結、刪除（依權限）
- [ ] 所有右鍵選單外觀一致、深淺色正確、鍵盤可操作（上下鍵、Enter、Esc），有快捷鍵的項目附角標
- [ ] 手機長按開啟，以底部抽屜呈現，觸控目標 ≥ 44 px，不超出螢幕
- [ ] 文字輸入框、編輯器內按右鍵仍是瀏覽器原生選單（保留拼字檢查與貼上）

### 測試流程
1. 依序在側欄專案、看板欄、紀錄列表、任務列表、留言、附件按右鍵，確認選單項目與權限相符
2. 用檢視者帳號重複一次，看不到編輯、刪除類項目
3. 手機寬度長按同樣的物件，底部抽屜開啟且可操作
4. 在留言輸入框按右鍵，出現瀏覽器原生選單
