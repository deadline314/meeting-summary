# [MS-24] 顯示提交歷史與排行榜

> 狀態：待辦

## 內文

### 需求
學生要能看自己的歷次提交與進步；開放排行榜的任務要能看到大家的最佳成績，老師要能看全部提交的整體狀況。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/04-tasks.md` §2、§3

### 驗收條件
- [ ] 學生：提交歷史列表（時間、狀態、分數），可比較兩次提交的分數與各測項差異；分數趨勢圖
- [ ] 排行榜（任務有開放時）：每人只顯示最佳成績，依分數方向排序，同分以較早提交者優先，標示自己的名次
- [ ] 管理員：所有提交列表、每人最佳成績、未通過原因統計、未提交名單；可下載提交檔與匯出 CSV
- [ ] 排行榜與列表分頁載入
- [ ] 名稱跟隨改名即時更新

### 測試流程
1. 三位學生各提交數次不同分數
2. 排行榜每人只出現一次且排序正確
3. 學生打開提交歷史看到分數趨勢圖
4. 管理員看到未提交名單並匯出 CSV
