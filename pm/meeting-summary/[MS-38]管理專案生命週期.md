# [MS-38] 管理專案生命週期

> 狀態：進行中

## 內文

### 需求
專案要能結案、重新開啟、封存、還原與永久刪除，且不會誤刪。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/05-project-management.md` §4（結案）、§5.8

### 驗收條件
- [x] 生命週期：進行中 → 已結案（可重新開啟）→ 已封存（可還原）→ 永久刪除
- [x] 只有驗收人、擁有者、管理員能結案，且必須走結案動作
- [x] 永久刪除必須先封存，並輸入專案 key 確認；確認框寫出後果
- [x] 專案 key 在永久刪除前不釋放
- [x] 封存父專案不連帶封存子專案
- [x] 側欄：已結案收合、已封存展開才載入

### 測試流程
1. 結案 CATS，側欄移到已結案；重新開啟後回到進行中
2. 未封存時看不到永久刪除
3. 封存後永久刪除，輸入錯誤 key 按鈕不可按，輸入正確後刪除
4. 封存父專案，子專案仍在進行中
