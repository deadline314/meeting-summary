# [MS-36] 支援議題附件與圖片標註

> 狀態：待辦

## 內文

### 需求
議題要能附檔案、圖片、Drive 檔案；貼截圖時能先畫紅框標註問題位置。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/05-project-management.md` §5.6 與「本平台的調整」

### 驗收條件
- [ ] 上傳方式：按鈕、貼上、拖放；檔案存平台儲存，規則與會議紀錄附件一致
- [ ] 貼上或拖放圖片時先開標註器：紅框、箭頭、文字、復原與重做，可略過
- [ ] 先上傳完成才登記附件，中斷不留下孤兒附件
- [ ] 可掛載既有 Drive 檔案：不套大小上限、不改 Drive 權限、移除時不刪來源檔
- [ ] 附件權限與專案一致

### 測試流程
1. 在議題貼上截圖，標註器開啟，畫紅框與文字後確認，附件顯示標註後的圖
2. 標註時按復原與重做，結果正確
3. 上傳途中斷網，附件區沒有殘留項目
4. 掛載一個 Drive 檔案後移除，Drive 檔案仍在
