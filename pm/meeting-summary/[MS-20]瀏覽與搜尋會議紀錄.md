# [MS-20] 瀏覽與搜尋會議紀錄

> 狀態：待辦

## 內文

### 需求
會議紀錄多了以後，要能快速找到某一份或某一段內容。

### 來源
使用者 2026-10-19 對話（初始需求）

### 驗收條件
- [ ] 列表依日期排序，顯示名稱、日期、記錄人、出席人數、未解決註解數
- [ ] 可篩選：日期範圍、專案、記錄人、出席者、有未解決註解；篩選狀態寫在網址，重新整理與分享可還原
- [ ] 全文搜尋標題與內文，結果標示命中的片段
- [ ] 提供月曆檢視，點日期看當天的會議
- [ ] 列表分頁載入，1000 份紀錄仍順暢
- [ ] 只列出使用者有權限讀取的紀錄，分頁數量正確

### 測試流程
1. 建立 3 份不同日期與專案的紀錄
2. 篩選某專案，網址更新；複製網址到另一分頁，顯示相同結果
3. 搜尋內文中的一個詞，結果標示命中片段
4. 切換月曆檢視，點日期看到該日會議
