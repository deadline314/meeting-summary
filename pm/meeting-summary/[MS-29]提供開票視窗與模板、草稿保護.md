# [MS-29] 提供開票視窗與模板、草稿保護

> 狀態：待辦

## 內文

### 需求
開票要快：快捷鍵開視窗、鍵盤完成所有欄位、可連續建立；用模板帶入格式；打到一半關掉也不會遺失。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/05-project-management.md` §5.1

### 驗收條件
- [ ] 按 C、工具列「新增」、看板欄頭「＋」（預帶該欄狀態，hover 說明會建立在哪個狀態）開啟
- [ ] 標題自動聚焦；底部 pill 依序：專案、模板、狀態 S、優先級 P、負責人 A、標籤 L，可用鍵盤操作
- [ ] ⌘／Ctrl+Enter 送出；勾「連續建立」送出後不關閉並清空
- [ ] 專案選單只列進行中且自己不是檢視者的專案
- [ ] 模板分個人、專案、全域，預設優先序個人 > 專案 > 全域；描述為空時自動帶入預設模板；換模板直接覆蓋且 ⌘Z 可還原
- [ ] 草稿自動存本機，重新開啟提示「已還原上次未送出的草稿」
- [ ] 打過字後 Esc、X、點外面都出現三選一：取消／刪除／保留草稿，焦點預設在保留
- [ ] 手機上開票視窗為全螢幕，pill 可橫向捲動

### 測試流程
1. 按 C 開視窗，只用鍵盤填完標題、狀態、優先級、負責人並送出
2. 勾連續建立，送出三張後視窗仍開著
3. 換模板覆蓋描述，按 ⌘Z 還原原本內容
4. 打字後按 Esc，選保留草稿；重新開啟看到還原提示與內容
