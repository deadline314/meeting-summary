# [MS-41] 提供站內通知與通知偏好

> 狀態：待辦

## 內文

### 需求
被指派、被提及、收到註解、評測結果出來時要收到通知，並能自己決定要收哪些。

### 來源
使用者 2026-10-19 對話（初始需求）；設計：`design/05-project-management.md` §10、§13；待確認 #3

### 驗收條件
- [ ] 事件：議題被指派、狀態變更、新留言、被提及；會議紀錄被註解與回覆；任務評測結果
- [ ] 訂閱者收通知；議題建立者與負責人自動訂閱；60 秒內同一張票的通知合併；自己做的動作不通知自己
- [ ] 通知鈴鐺顯示未讀數，列表可標已讀、全部已讀，點擊前往對應位置
- [ ] 清單上有未讀通知的票顯示紅點
- [ ] 偏好設定為「專案 × 事件」矩陣，分進行中、已結案、已封存三區，有全選與全不選；沒有設定即為開啟
- [ ] 通知在資料寫入成功後才送出；單一收件人失敗不影響其他人與主流程
- [ ] 通知即時出現（不需重新整理）

### 測試流程
1. B 把 CATS-1 指派給 A，A 的鈴鐺即時出現未讀
2. B 在 60 秒內連改 CATS-1 三次，A 只收到一則合併通知
3. A 在偏好關閉 CATS 的狀態變更，B 改狀態後 A 沒收到
4. A 提交任務，評測完成後收到結果通知
